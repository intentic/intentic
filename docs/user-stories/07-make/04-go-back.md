# Go back

As someone who does not write code, I want to undo the last change from the page that lists it, so that a wrong turn costs one press and no vocabulary.

A change I asked for made the homepage worse. On the Project page I open its What's new row and press Go back to before this. The page says what will happen in plain words and asks once. After I confirm, the files are as they were before that change, a new row says I went back, and the row I went back from is still there above it.

## Acceptance criteria

- [ ] Every What's new row offers "Go back to before this", which asks for confirmation in plain words before doing anything
- [ ] After confirming, the project's files are as they stood before that point, and the Files list on the page reflects it
- [ ] What's new gains a row saying the files were restored, and keeps the rows for what came before and after
- [ ] Nothing about the git branches or the sandbox's secrets changes
