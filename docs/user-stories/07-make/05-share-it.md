# Share it

As someone who does not write code, I want one place that says what of mine is out on the internet and how to put something there, so that "shared" and "published" mean the same thing everywhere I see them.

From the Project page I press Share. It opens the sandbox's Public tab: the folder whose contents anyone with the link can open, and the address they open it at. In the file tree that folder wears a chip that says "shared" rather than "public". The git act of copying my work to GitHub is called Back up, never Publish.

## Acceptance criteria

- [ ] Share on the Project page opens the Public tab, which names the folder and its public address
- [ ] The workspace tree marks that folder "shared" for the maker audience and "public" for the developer's, with the same warning tone either way
- [ ] Where the developer's Changes panel says Publish or Push, the maker's words say Back up
