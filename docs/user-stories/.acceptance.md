# Testing notes for intentic itself

These notes are appended to every acceptance brief for this repository. They exist because the app
under test is the same kind of thing as the tester: an agent walking intentic can start other agents,
spend money, and land code. Read all of it before the first click.

## Signing in

The web app requires a session. A fresh browser has none, so **your first act is to sign in** at
`/login` with the acceptance account for this environment. If no such account has been provisioned,
that is not something to work around: record the story as `blocked`, with "no acceptance account" as
the wall you hit, and stop. Do not sign up, do not reset anyone's password, and do not attempt to
reach the API directly to mint a session.

## Money and blast radius

Several of these stories ask you to start an agent. That is real: it runs a real model against a real
provider and it costs real tokens.

- Start **at most one** agent per story, give it a trivial task ("print the current date"), and pick
  the cheapest model offered.
- **Stop and discard the agent you started** before you finish the story. Leave the board as you
  found it.
- Never act on an agent you did not create — no landing, no discarding, no archiving, no renaming.
  Other people's work is running on this board.
- Never press "Delete all" in the archive. It is the one irreversible action in the product.
- Do not connect capabilities, do not add or reveal secrets, and do not create or destroy sandboxes.

## Reading the app

- The three surfaces most stories start from are `/agents` (the fleet board), `/workspace` (the file
  tree and changes) and `/ext/acceptance` (this area). The rail on the left reaches all of them.
- Much of the UI updates by polling rather than on navigation. When something has not appeared yet,
  wait and re-snapshot before calling it a defect — but say in the report how long you waited.
- The chat panel is docked beside the middle column on a wide window and is a separate screen on a
  narrow one. If a story's flow seems to be missing, check the viewport width before reporting it.
