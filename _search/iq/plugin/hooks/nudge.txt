`iq` is a pre-installed CLI available in this workspace — an intent-first code search tool that fuses lexical, structural, semantic, and git search into one call returning ranked `path:line` anchors. Prefer it over grep/find/Glob chains for locating code, symbol definitions/references, structural patterns, and natural-language code questions. Run `iq --help` or consult the `iq` skill for the verb cheat-sheet.
